# Changelog

All notable changes to CIRCULUS are documented here.

## [1.0.0] - 2026-11-10
### Added
- Complete FastAPI backend architecture with async SQLAlchemy 2.0 and PostgreSQL support.
- Comprehensive database migration suite (36 tables with full RLS policies and performance indexes).
- Full authentication & invitation registration engine with single-use, expiring keys and verification gates.
- Flutter mobile client with Material Design 3, CIRCULUS Midnight Navy & Premium Gold branding.
- Brain Arena with interactive Sudoku engine, Governance & GK quiz, and Executive Memory Challenge.
- Centralized Points Engine with automated Weekly Podium calculation and permanent achievement archives.
- Direct 1-to-1 and group messaging system with conversation membership validation.
- Responsive React TypeScript administration dashboard for member approvals and invitation management.
- Complete automated test suite covering game validation and anti-cheat security.
- Comprehensive technical documentation, architecture diagrams, and Android installation guide.
